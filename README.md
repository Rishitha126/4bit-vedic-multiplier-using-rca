# 4-Bit Vedic Multiplier Using Ripple Carry Adder (RCA)

## Overview

This project presents the design and implementation of a 4-bit Vedic Multiplier based on the Urdhva Tiryakbhyam (Vertical and Crosswise) algorithm. The design uses Ripple Carry Adders (RCA) to sum intermediate partial products and generate the final multiplication result.

## Objectives

* High-speed multiplication using parallel partial-product generation
* Efficient hardware utilization
* Simple and modular architecture
* Scalability for higher bit-width multipliers

## Design Components

* 4-Bit Vedic Multiplier
* 2×2 Vedic Multiplier Blocks
* Ripple Carry Adders (RCA)
* Full Adders and Half Adders
* Partial Product Generation Logic

## Files Included

* Verilog HDL Source Code (.v)
* Constraint File (.sdc)
* Simulation Results
* Synthesis Results
* Area and Power Reports
* Project Report

## Results

* Functional correctness verified through simulation
* Successful synthesis and hardware implementation
* Modular and scalable architecture
* Efficient multiplication using the Vedic algorithm

## Applications

* Digital Signal Processing (DSP)
* FPGA-Based Systems
* VLSI Design
* Embedded Systems

## Future Scope

The design can be extended to 8-bit, 16-bit, and higher-bit multipliers for high-performance arithmetic applications.
